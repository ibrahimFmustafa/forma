# Forma — مساحة مفتوحة لأفكارك

محرر تصميم متجهي مفتوح المصدر، بمحرك **Rust / WebAssembly** وواجهة TypeScript خفيفة تعمل في المتصفح. هذا إصدار **ألفا 0.1** قابل للاستخدام كبداية لبديل مفتوح لـ Figma، وليس بديلًا مكتملًا بكل مزاياه.

الكود والواجهة والتصميم التجريبي أصلية. أُعيد تنفيذ الوظائف العامة لأدوات التصميم، دون نسخ مشروع قائم أو تفكيك ملفات تنفيذية مملوكة أو ادعاء التوافق مع صيغة `.fig`.

[جرّب المحرر في المتصفح](https://ibrahimfmustafa.github.io/forma/)

## التشغيل

ثبّت Node.js إصدار 22.12 أو أحدث، ثم:

```sh
git clone https://github.com/ibrahimFmustafa/forma.git
cd forma
npm ci
npm run dev
```

افتح العنوان الذي يظهر في الطرفية. يتضمن المستودع نسخة WebAssembly مبنية من محرك Rust، لذلك لا تحتاج Rust لمجرد تجربة المحرر.

لبناء المحرك من المصدر بعد تثبيت Rust:

```sh
rustup target add wasm32-unknown-unknown
npm run build:engine
npm test
npm run build
```

## الوظائف المتاحة

- مساحة رسم مع التكبير والتحريك، ومستطيلات ودوائر ونصوص وإطارات وخطوط ورسم حر.
- طبقات متداخلة مع الإخفاء والقفل والترتيب وتغيير الإطار الأب.
- تحديد متعدد، وتحريك وتحجيم ودوران للأشكال، ومحاذاة وتعديل القيم بدقة.
- تعديل الألوان والحدود والزوايا والشفافية وحجم النص ووزنه.
- تراجع وإعادة ينفذهما Rust، مع دمج عملية السحب في خطوة تراجع واحدة.
- نسخ ولصق داخل المحرر، وقوالب أزرار وبطاقات وإطارات أجهزة قابلة للتعديل.
- حفظ تلقائي في المتصفح، وفتح وحفظ ملفات `.forma`، وتصدير SVG وPNG.
- مشروع تجريبي أصلي، ومساعدة واختصارات لوحة مفاتيح.

الواجهة الحالية بالإنجليزية، وتدعم بيانات المستند نصوص Unicode بما فيها العربية. تحرير النص يتم من لوحة الخصائص، مع فواصل أسطر يدوية. دعم العربية ليس توطينًا كاملًا للواجهة.

## حدود الإصدار

لا توجد مشاركة لحظية، أو استيراد ملفات Figma، أو مكونات مترابطة، أو تخطيط تلقائي، أو استيراد صور، أو تحرير منحنيات Bézier، أو نماذج تفاعلية حتى الآن. الإطارات بإحداثيات مطلقة دون قص للمحتوى أو تدوير جماعي. هذا أساس عملي قابل للتطوير وليس منتجًا مكافئًا لـ Figma.

المستندات تبقى على جهازك. الحفظ التلقائي يحتفظ بمستند واحد لكل عنوان موقع؛ نزّل ملف `.forma` للاحتفاظ بنسخ احتياطية. حد المستند 2000 طبقة، وحد الاستيراد 8 ميغابايت، وسجل التراجع 80 خطوة ولا يستمر بعد إعادة تحميل الصفحة. يُفضّل استخدام شاشة مكتبية ولوحة مفاتيح وفأرة.
